GitHub is a web-based cloud platform that stores and manages Git repositories, allowing developers to collaborate on software projects, track code changes, and build applications together. [1, 2, 3, 4] 
------------------------------
## How GitHub Works

* Git vs. GitHub: Git is the local, open-source version control system installed on your computer to track code changes. GitHub is the online cloud service that hosts those Git projects, making them accessible from anywhere. [1, 3, 5] 
* Repositories (Repos): A repository acts as a project folder containing all your code files, documentation, and complete revision history. [3, 6, 7] 
* Branches: Separate working copies of a project that let developers safely build new features or fix bugs without breaking the main production code. [8, 9] 
* Commits: Saved snapshots of changes made to files in a repository, complete with a message describing what was altered. [8] 
* Pull Requests (PRs): Proposed changes from a branch that teammates can review, discuss, and test before merging them into the main project. [8, 10] 

------------------------------
## Core Features and Uses

* Collaboration: Teams can work asynchronously, review each other's code, manage tasks, and track bugs.
* Open Source: Developers around the world can share public code, study others' projects, "fork" (copy) projects, and contribute improvements.
* Automation (CI/CD): Built-in tools like GitHub Actions automate testing, building, and deploying software updates.
* Security & AI: Features automated vulnerability scanning, secret detection, and AI-powered coding assistants like GitHub Copilot. [2, 4, 6, 11, 12]
